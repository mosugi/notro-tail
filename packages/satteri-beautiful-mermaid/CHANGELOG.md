# satteri-beautiful-mermaid

## 0.1.0

### Minor Changes

- [#173](https://github.com/mosugi/notro/pull/173) [`28020aa`](https://github.com/mosugi/notro/commit/28020aa37bbb5f48be8e3e812ae1442907aad022) Thanks [@mosugi](https://github.com/mosugi)! - Initial release. Successor of the discontinued `rehype-beautiful-mermaid`: the same build-time Mermaid-to-SVG rendering (via `beautiful-mermaid`), rebuilt as a Sätteri hast plugin for Astro 7's Rust-based Markdown/MDX processor. Export changed from `rehypeMermaid` (rehype plugin) to `satteriMermaid(options)` (plugin factory); the `theme` and `className` options are unchanged.
